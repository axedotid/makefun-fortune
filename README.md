# Fortune Cookie Wisdom for Developers

`main.ts` writes a single original line of fortune-cookie wisdom for a software
developer to `/output/entry.txt` (falling back to `./entry.txt` if `/output` is
not writable). The line plays on how the hasty "temporary" fix is often the only
part of a project that survives to production, while the careful work around it
gets cut. Run it with `npx tsx main.ts` or `node main.ts`.
